# Salah Bar for Android

Prayer times on your phone: a live countdown to the next prayer, the full adhan at prayer time
(on time with the screen off), reminders before each prayer and before the iqama, a prayer log,
Friday and Sunnah reminders, dhikr cards and a Ramadan companion, in twelve languages. Everything
is calculated on the phone: no account, no ads, no data collected.

The Android version of [Salah Bar for Mac](https://github.com/be-liever95/salah-bar)
(also for [Windows](https://github.com/be-liever95/salah-bar-windows-releases)).
